# 연구실 홈페이지 편집 안내

홈페이지의 소개, 교수 정보, 연구 분야, 논문, 구성원과 졸업생은 [Pages CMS](https://app.pagescms.org/)에서 입력 양식으로 편집하도록 구성되어 있습니다. 저장하면 GitHub 저장소의 내용이 바뀌고, GitHub Pages 배포가 완료된 뒤 홈페이지에 반영됩니다.

**현재 준비 범위:** 편집 설정 파일과 홈페이지용 데이터 구조를 제공합니다. Pages CMS 계정 연결, 앱 설치, 실제 저장 및 공개 사이트 반영은 계정 소유자의 최초 연결과 배포 설정 후 확인해야 합니다. 이 안내 자체가 연결이나 공개 배포 완료를 뜻하지는 않습니다.

## 처음 한 번 연결하기

1. [Pages CMS](https://app.pagescms.org/)에 접속해 GitHub 계정으로 로그인합니다.
2. Pages CMS GitHub App 설치 화면에서 저장소를 소유한 `jnu-csplab` 계정을 선택합니다. 설치 대상은 **Only select repositories**에서 **`labwebsite`만** 선택합니다. 이미 설치했다면 이 저장소에 접근할 수 있도록 설치 범위를 확인합니다.
3. Pages CMS에서 `jnu-csplab/labwebsite`를 엽니다. 홈페이지를 배포하는 브랜치를 선택합니다. 이 브랜치에 `.pages.yml`이 있어야 한국어 편집 항목이 나타납니다.
4. 아래 편집 메뉴가 보이는지 확인합니다. 새 설정 파일을 만들라는 화면이 나오면 저장소와 브랜치를 다시 확인합니다.

이 프로젝트에는 별도의 CMS 서버를 설치할 필요가 없습니다. GitHub 로그인과 GitHub App 연결 방식은 [Pages CMS 공식 시작 안내](https://pagescms.org/docs/quick-start/)를 따릅니다.

## 어디에서 무엇을 고치나요?

| 편집 메뉴 | 변경할 내용 |
| --- | --- |
| 연구실 기본 정보 | 연구실 이름, 소속, 메인 제목, 소개, 연락처, 모집 안내 |
| 교수 소개 | 성함, 직위, 소개, 사진, 학력·경력, Scholar, 이력서 PDF |
| 연구 분야 | 분야별 제목, 짧은 소개, 상세 설명, 이미지, 표시 순서 |
| 논문 | 제목, 저자, 연도, 학술지·학회, 논문 구분, DOI, PDF, 코드 링크 |
| 구성원 및 졸업생 | 성명, 과정, 연구 관심사, 사진, 연락처, 재실·졸업 구분 |

각 항목의 한국어 설명에 맞춰 입력하고 **Save(저장)**를 누릅니다. 빈 선택 항목은 비워 두어도 됩니다. 외부 홈페이지 링크에는 `https://`로 시작하는 전체 주소를 입력합니다.

## 연구 분야·논문·구성원 추가하기

이 세 메뉴는 목록 전체를 한 화면에서 편집합니다. 새 파일을 만들거나 파일 이름을 정할 필요가 없습니다.

1. 원하는 메뉴를 열고 목록의 **추가(Add)** 기능으로 항목을 하나 추가합니다.
2. 제목이나 이름 등 필수 내용을 입력합니다. 실제로 확인된 정보만 등록합니다.
3. 필요한 경우 목록의 순서 변경 기능으로 항목을 옮깁니다. 연구 분야의 웹사이트 표시 순서는 **표시 순서** 숫자가 우선하므로 이 숫자도 조정합니다.
4. 목록 전체를 확인한 후 **Save(저장)**를 누릅니다. 저장 전 화면을 닫으면 변경 사항이 사라질 수 있습니다.

같은 목록을 여러 사람이 동시에 수정하면 서로의 변경이 겹칠 수 있습니다. 편집을 시작하기 전에 최신 내용을 다시 열고, 한 번에 한 사람이 저장하는 방식이 편리합니다.

### 논문 등록

논문 제목, 저자 순서, 발행 연도, 논문 구분을 입력합니다. 학술지·학회 이름과 DOI는 원문에 맞춰 적습니다. 논문 웹 주소, PDF, 코드 저장소는 있는 것만 추가합니다. 홈페이지에서 강조할 논문에는 **대표 논문으로 표시**를 켭니다.

### 졸업생(Alumni)으로 옮기기

기존 구성원 항목을 열어 **재실 및 졸업 구분**을 **졸업생**으로 바꾸고, 졸업 연도와 졸업 후 소속을 입력한 뒤 저장합니다. 기존 항목을 복사하거나 새로 만들 필요가 없습니다. 과정 및 직위에는 연구실에 재실했을 때의 과정을 유지합니다.

## 사진과 PDF 올리기

사진 항목의 업로드 기능은 PNG, JPG, JPEG, WebP를 지원합니다. 이력서와 논문 PDF 항목에는 PDF 파일을 업로드합니다. 업로드한 파일은 저장소의 `media` 폴더에 보관됩니다. 선택 후 만들어진 경로는 그대로 사용하면 됩니다.

교수·구성원 사진은 정사각형 또는 세로 인물 사진, 연구 이미지는 가로 이미지가 편리합니다. 사진이 없으면 해당 항목을 비워 둡니다. 공개해도 되는 사진과 논문 파일만 등록합니다.

미디어 창에서 파일을 삭제하면 해당 파일을 사용하는 다른 항목에서도 사진이나 문서가 열리지 않을 수 있습니다. 먼저 사용 중인 항목을 확인합니다.

## 저장한 내용이 보이지 않을 때

1. CMS에서 **Save**를 눌렀는지, 올바른 브랜치에 저장했는지 확인합니다.
2. [저장소의 Actions 화면](https://github.com/jnu-csplab/labwebsite/actions)에서 해당 변경의 GitHub Pages 배포가 완료되었는지 확인합니다.
3. [저장소의 Pages 설정](https://github.com/jnu-csplab/labwebsite/settings/pages)에서 배포 주소와 배포 방법이 설정되어 있는지 확인합니다. 최초 배포 설정이 끝나기 전에는 공개 주소에서 볼 수 없습니다.
4. 배포 성공 뒤 홈페이지를 새로고침합니다. 실패로 표시되면 실패한 실행 화면을 담당자에게 전달합니다.

삭제하거나 잘못 수정한 내용은 GitHub의 변경 기록에 남습니다. 복원이 필요하면 해당 변경의 기록을 확인해 되돌릴 수 있습니다.

## 설정 참고

편집 양식은 저장소 루트의 `.pages.yml`에 정의되어 있습니다. 연구 분야·논문·구성원은 공식 문서의 [파일 최상위 배열 설정](https://pagescms.org/docs/configuration/content/list/)을 사용하며, 사진과 PDF 저장 위치는 [미디어 설정](https://pagescms.org/docs/configuration/media/)을 따릅니다. 일상적인 내용 편집에는 이 파일을 수정할 필요가 없습니다.
